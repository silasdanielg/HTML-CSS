Módulos HTML • 01

HTML5 Básico & Tags Fundamentais

HTML (HyperText Markup Language) é a estrutura básica da Web. Cada tag define um tipo de elemento estrutural ou de conteúdo.

<!DOCTYPE html>

Declaração de Tipo

Informa ao navegador que o documento utiliza a especificação HTML5 moderna.

<html> e <head>

Raiz e Metadados

`html` engloba todo o documento. `head` guarda metadados, títulos, links CSS e scripts.

<body>

Corpo Visível

Contém todo o conteúdo visual renderizado na tela para o usuário final.

<h1> até <h6>

Títulos e Cabeçalhos

Definem a hierarquia do texto. `h1` é o título principal (máximo 1 por página).

<p>, <span>, <div>

Parágrafos e Divisores

`p` para texto de bloco. `div` é container genérico em bloco. `span` para linha.

<a> e <img>

Links e Mídias

`a` cria hiperlinks com `href`. `img` exibe imagens com `src` e atributo `alt` obrigatório.

estrutura-base.html 
<!-- Estrutura padrão de um documento HTML5 -->
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Primeiro Projeto</title>
</head>
<body>
    <h1>Olá, Mundo!</h1>
    <p>Este é um parágrafo contendo um <a href="https://google.com" target="_blank">link externo</a>.</p>
    <img src="foto.jpg" alt="Descrição acessível da imagem">
</body>
</html>
Módulos HTML • 02

HTML Semântico & SEO

Usar tags semânticas significa dar significado ao conteúdo para motores de busca (Google SEO) e leitores de tela para pessoas com deficiência visual.

Esquema Estrutural de uma Página Semântica

<header> (Cabeçalho da página ou logotipo / navegação)
<nav> (Links de navegação principal)
<main> (Conteúdo principal)
<article> (Conteúdo autônomo, post de blog ou notícia)
<section> (Seção temática do documento)
<aside>
(Barra lateral, recomendações ou anúncios)
<footer> (Rodapé, direitos autorais, links sociais)

Módulos CSS • 04

CSS Seletores & Sintaxe

Cascading Style Sheets define a apresentação visual. Os seletores escolhem quais elementos HTML serão estilizados.

Seletor Elemento

Por Tag HTML

Afeta todas as tags do tipo especificadas.

h1 { color: #3b82f6; }
Seletor Classe (.classe)

Por Classe Reutilizável

Aplica estilo em qualquer tag com o atributo `class`.

.cartao { background: #1e293b; }
Seletor ID (#id)

Por ID Único

Aplica a um elemento individual com ID específico.

#topo { position: sticky; }
Pseudo-classes (:hover)

Estados e Interatividade

Aplica quando o usuário interage (mouse por cima, foco).

button:hover { opacity: 0.8; }

Módulos CSS • 06

Unidades de Medida & Cores

Valores de dimensionamento relativo vs absoluto e formatos de cores modernas.

Unidades de Medida

  • px (Pixels): Absoluto. Tamanho fixo e não escala automaticamente.
  • rem: Relativo ao `font-size` da raiz (`<html>`). Padrão 1rem = 16px. Ideal para responsividade!
  • em: Relativo ao tamanho da fonte do próprio pai direto do elemento.
  • vw / vh: 1vw = 1% da largura da tela (viewport width). 1vh = 1% da altura da tela.

Sistemas de Cores

  • HEX: `#3b82f6`
  • RGB / RGBA: `rgb(16, 185, 129)`
  • HSL: `hsl(270, 91%, 65%)`

Módulos CSS • 09

Posicionamento no CSS

Controla a localização do elemento no fluxo do documento.

static (Padrão)

Segue o fluxo normal da página. Não aceita top/left/z-index.

relative

Desloca-se em relação à sua posição original sem afetar outros elementos.

absolute

Posiciona-se em relação ao seu ancestral mais próximo que possua `position: relative`.

fixed / sticky

`fixed` fixa na tela inteira. `sticky` fixa ao rolar a página até certo limite.
